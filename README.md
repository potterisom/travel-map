# Leila's travel map

Upload this folder's **contents** to the `potterisom/map` GitHub repository.

Enable **Settings → Pages → Deploy from a branch → main → /(root)**.

The site will be available at `https://potterisom.github.io/map/` once GitHub finishes publishing.

**Your regular editing workflow:**
- Edit `content.js` on GitHub to add cities, change country statuses, and write stories.
- Upload photographs to `photos/`, then list their paths in the city's photo array.
- Commit your changes. GitHub updates the site automatically.

No build commands or npm installation are required. The public site is view-only; editing requires repository write access.

Read **EDITING-GUIDE.md** for complete, copyable examples. **COUNTRY-NAMES.md** lists accepted country names.
